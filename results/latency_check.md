- Look-ahead: worst case over 16 positions within a hop; the measured value stays below the M − 1 bound because the synthesis window is zero at its edge.
- Streaming delay: impulse through the frame-by-frame implementation (`dwmss/streaming.py`); worst-case algorithmic latency = delay + hop − 1 samples = M − 1.
- Per-hop compute: full pipeline (STFT, network, mask, iSTFT) with ONNX Runtime on one CPU thread (`results/latency_benchmark.md`). The real-time factor is the mean; the P99 and the share of hops over the hop duration show whether individual callbacks meet the deadline. Measured in Python on a shared cluster node; a deployed system would run in a dedicated real-time audio thread.
- End-to-end latency through an audio interface (driver and device buffers) is not measured.
